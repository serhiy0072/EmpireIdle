# Спрайти будівель

Файл `<ключ будівлі>.png` (ключ — як у `buildings.json`: `townhall`, `barracks`…).
Поки файлу немає в маніфесті `src/components/village/sprites.ts`, будівля малюється
процедурним силуетом із `buildingArt.tsx` — тому додавання спрайта це два кроки:
покласти PNG сюди й вписати його в маніфест.

## Конвенція

- Ізометрія 2:1, погляд з південного сходу (як у силуетів). Прозорий фон.
- Ширина спрайта відповідає ширині ромба основи: для основи `foot = 4`
  це 160 px світу; спрайт масштабується до цієї ширини, висота — з пропорції.
- Якір — нижня вершина ромба основи: нижній центр PNG стає на цю точку.
  Тінь на землі малюється кодом, у PNG її не потрібно.
- Варіанти за рівнем (необов'язково): `<ключ>_2.png`, `<ключ>_3.png` — тір 2 (рівні 5–9)
  і тір 3 (10+). Без варіанта береться базовий файл.
- Рекомендований розмір: 512 × 512 (ширина ромба ≈ 480 px), щоб на зумі 6× не мило.
